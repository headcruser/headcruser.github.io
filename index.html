03 · Proyectos

Casos reales, en producción

Cada proyecto cuenta el problema, lo que construí y el resultado para el cliente.

Covemex

ERP Regina

Problema
No contaban con una herramienta para gestionar su información interna.
Qué hice
Desarrollé una plataforma para registrar la producción, los empleados y los proveedores de la empresa.
Resultado
Informes de producción generados desde el sistema y gestión centralizada de proveedores.
  • Laravel
  • SQL Server

TGAB / Covemex

Help Desk

Problema
La plataforma de soporte era obsoleta y el departamento de TI no podía demostrar el trabajo que realizaba.
Qué hice
Desarrollé un sistema de tickets para que los usuarios de la empresa registren y den seguimiento a sus solicitudes.
Resultado
Los usuarios consultan sus solicitudes de forma rápida y sencilla, y TI cuenta con un registro que respalda su trabajo.
  • Laravel
  • SQL Server

ADN Digital

Facturación y Cartas Porte

Problema
Los negocios necesitaban emitir y gestionar sus facturas y cartas porte, requisito fiscal del SAT, desde un solo lugar.
Qué hice
Desarrollé, junto con el equipo, una plataforma de facturación y cartas porte que cada negocio adapta a sus necesidades.
Resultado
Un sistema escalable que se ajusta a cada empresa que lo contrata.
  • Laravel
  • SQL Server

Yutaka · Industria automotriz

DIGIMAS · Digital Management System

Problema
La información de los asociados estaba repartida entre los distintos departamentos de la empresa.
Qué hice
Participo en el desarrollo de DIGIMAS, un ERP con módulos para Recursos Humanos, Producción y Capacitación, en web y móvil.
Resultado
Información de los asociados centralizada, métricas clave para cada departamento y herramientas que usa el área de producción.
  • Vue
  • .NET
  • Flutter
  • SQL Server
  • Reporting Services
